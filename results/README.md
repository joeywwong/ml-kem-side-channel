# Generated summaries

These small JSON reports and labeled PNG figures are generated by actual runs.
`simulation.json` and simulation plots are **SIMULATED**, never captured power.
`benchmark.json` is **HOST TIMING**, never MCU cycles. `host-mlkem.json` records
NIST KAT and randomized functional results. See `docs/RESULTS.md` for interpretation.

Raw synthetic datasets, build products, logs and any future physical traces stay
under ignored `local-results/` and `build/`. No physical traces exist in this run.
Reproduce with `python tasks.py all`; dependencies are pinned in requirements.txt
and upstream source/vector URLs plus SHA-256 digests in `upstream-lock.json`.
